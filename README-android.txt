1) فك الضغط وانسخ المحتويات (.github و android-app و .vercelignore) لجذر المستودع وارفعها.
2) بـ GitHub: Settings > Secrets and variables > Actions > Variables > New repository variable
   الاسم: APP_URL    القيمة: رابط فيرسل مثل https://اسم-مشروعك.vercel.app
3) تبويب Actions > Build Android APK > Run workflow (أو أي push يشغله).
4) بعد ما يخلص (5-8 دقايق) افتح قسم Releases بالمستودع ونزّل layla-al-abtal.apk من جوالك وثبته.
   (فعّل "السماح بالتثبيت من هذا المصدر" إذا طلب الجوال).
